# UX Portfolio

UX and product design case studies, plus AI experiments. Single-page landing (Overview / Work / About / Archives) with detailed case-study pages.

Stack: Astro + MDX + GSAP. See [PLAN.md](PLAN.md).

```bash
npm install
npm run dev     # http://localhost:4321
npm run build
```

- Profile placeholders: `src/data/site.ts`
- Case studies: `src/content/work/*.mdx`; experiments: `src/content/archives/*.mdx`
- MDX components: `src/components/mdx/`
